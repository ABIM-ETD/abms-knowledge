# Using Large Language Models to Reduce the Workload for Volunteers Reviewing Improving Health and Health Care Diplomate Submissions

**Thursday, 2026-09-17** · 10:45 AM - 11:45 AM CST

**Topic:** [[Artificial Intelligence]]

## Speakers

- [[Nathan W. Sanders]] — Senior Web Application Developer, The American Board of Physician Medicine and Rehabilitation, Minnesota

## Description

As part of the American Board of Physician Medicine and Rehabilitation (ABPMR) Continuing Certification program, diplomates must submit an IHHC project once every five years. This results in over 1500 project submissions each year.

Prior to 2026, every submission was reviewed manually by an ABPMR Board Member. The resulting workload was not sustainable, so several changes have been made in 2026 to improve this process.

One adjustment was to bring on additional volunteer reviewers. The other change, which is the focus of this presentation, was to launch a pilot program using an AI LLM to review every submission.

Diplomate submissions are made through an online platform. The resulting submission is fed to an AI LLM and an email with the AI's determination is sent to a staff member. This determination is included when the review task is assigned to a volunteer reviewer. The diplomate does not see the AI's feedback about their submission. The reviewer uses the AI feedback to help inform their manual review.

This presentation will cover the LLM system prompt strategy used, along with the project genesis, initial testing, pilot phase, and update of the current state of things. It will explore the different technologies involved and the ways the human reviewers use the AI feedback they are given. It will also include feedback from our volunteers using the system and explore the road ahead for this project.Learning Objectives: Upon completion, participant will be able to describe how ABPMR is using an AI LLM in a real-world setting to reduce volunteer workload.Upon completion, participant will be able to list the pros and cons of involving AI with submission review tasks.
