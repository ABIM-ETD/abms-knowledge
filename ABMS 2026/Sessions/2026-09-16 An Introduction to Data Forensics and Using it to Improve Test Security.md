# An Introduction to Data Forensics and Using it to Improve Test Security

**Wednesday, 2026-09-16** · 11:00 AM - 12:00 PM CST

**Topic:** [[Emerging Topics]]

## Speakers

- [[Carol L. Barry, PhD (she-her-hers)]] — Director of Psychometrics and Research, American Board of Surgery, Pennsylvania
- [[Carol Eckerly, PhD]] — Assessment Security Manager, American Board of Internal Medicine, New Jersey
- [[Marcus Scott, PhD]] — Director of Data Forensics, Caveon

## Description

Data forensics is the statistical analysis of test data to detect unusual patterns that may be associated with test fraud. It is a valuable component of a testing organization’s security process that provides unique insight into exam response data.

This session first introduces data forensics, with emphasis on the types of results that can be obtained from data forensics and the statistics used to obtain those results. Representatives from the American Board of Surgery and the American Board of Internal Medicine will give examples of how their programs use the results of data forensics analysis. Discussion will include 1) how tests flagged with anomalous results are handled, 2) how data forensics results inform additional analyses and deeper investigations, and 3) how data forensics results are used to support program-level decisions and changes that improve test security and subsequently the validity of inferences made based on test scores.Learning Objectives: Understand what data forensics is and what kind of information it gives about exams, items, and test score validity.Understand the types of statistics used in data forensics analysis and what those statistics can detect.Understand how testing organizations can use data forensics to improve test security.
