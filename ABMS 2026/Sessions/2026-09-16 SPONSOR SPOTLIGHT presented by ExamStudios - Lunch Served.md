# SPONSOR SPOTLIGHT presented by ExamStudios | Lunch Served

**Wednesday, 2026-09-16** · 12:15 PM - 1:15 PM CST

## Description

Advanced Item Types Developed in ExamStudio and Delivered Anywhere

See what's possible when advanced item types meet reliable exam delivery. This session showcases how ExamStudio empowers testing organizations to build interactive assessment experiences, including rich patient and medical cases that can be paired with everything from standard multiple choice to advanced in-system item types such as drag-and-place, hot spot, and fill-in-the-blank. You'll also see how to display and interact with rich media seamlessly using the Advanced Media Player, a powerful suite of precision tools built for specialized assessment needs.

Want to go further? Get a behind-the-scenes peek into the collaborative storyboarding and development processes behind the advanced item types, interactive simulations, and optimized 3D models the Zoomorphix team is known for.

We will demonstrate engaging, well-designed examples in the ExamStudio Web Delivery Plus driver, which supports both online and offline delivery for flawless performance with advanced item types in high-stakes testing environments.

The presentation will begin at 12:30pm for approximately 30 minutes.
